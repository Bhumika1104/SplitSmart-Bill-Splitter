## 🚀 About the Project
**SplitSmart** is a feature-rich, full-stack expense-splitting platform engineered to handle shared finances among friends, flatmates, or travel groups. It eliminates manual calculation headaches by automating individual shares, tracking group spending, and running smart debt-simplification algorithms to settle balances efficiently with minimal transactions.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS, JavaScript (ES6+), HTML5
* **Backend:** Java, Spring Boot, RESTful APIs
* **Security & Auth:** Spring Security, JSON Web Tokens (JWT)
* **Database:** MySQL
* **API Testing:** Postman
* **Utilities:** PDF Generation Libraries, Image/Receipt Handling

---

## ✨ Key Features

### 👤 1. Authentication & Smart Dashboard
* **Secure Auth:** Encrypted user registration and login protected with Spring Security & JWT.
* **Unified Dashboard:** View total overall spending across all groups at a glance.
* **Net Balance Overview:** Instantly track the total amount you owe versus the amount you are owed.

### 👥 2. Group & Member Management
* **Custom Groups:** Create dedicated groups for apartments, trips, or events.
* **Member Invitations:** Add members seamlessly and send group invites.
* **Smart Group Search:** Instantly filter and search groups by their name.

### 💸 3. Expense Tracking & Receipts
* **Add Shared Bills:** Record multi-user bills within specific groups.
* **Receipt Attachments:** Upload image proofs/receipts for transparent bill tracking.
* **PDF Reports:** Download all group bills and individual reports in professional PDF formats.

### 🤝 4. Intelligent Settlements & Approvals
* **Debt Simplification:** Automatically calculates direct optimized settlements (e.g., bypassing intermediate payers to minimize transaction chains).
* **Payment & Approval Workflow:** Users log payments made (cash/digital), and recipients review/accept to clear balances dynamically.
* **Settlement Receipts:** Export downloadable PDF receipts for completed transactions.
